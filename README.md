# 小さくWeb化 — Webシステムサンプルサイト

Excelや紙で管理している業務を、小規模なWebシステムにした場合の画面イメージを確認するための静的デモサイトです。ココナラの「Excel・紙管理を小さなWebシステムにします」サービスで利用します。

## 現在公開しているサンプル

- 予約・スケジュール管理
- 在庫・備品管理
- 顧客・案件管理
- 日報・報告書管理
- 申請・承認管理
- 売上・請求管理

このサイトは画面イメージ用のデモであり、入力データは保存されません。

## ローカル起動方法

リポジトリのルートで以下を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## GitHub Pages

GitHub Pagesで公開することを想定した、HTML / CSS / JavaScriptのみの静的サイトです。外部ライブラリやサーバーサイド処理には依存していません。PRマージ後、GitHubの `Settings → Pages → Deploy from a branch → main → /root` を選択して公開できます。
